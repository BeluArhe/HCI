# Aleluyagarden - Sitio Web

## 📋 Descripción
Sitio web completo para Aleluyagarden, institución educativa cristiana para niños.

## 🎨 Colores del Diseño
- **Primario (CTA)**: #FF8C00 (Naranja/Terracota) - Botones de acción
- **Secundario (Estabilidad)**: #5D3E7B (Morado/Maroon) - Header, footer
- **Contacto/Vida**: #4CAF50 (Verde brillante) - Botones de contacto
- **Fondo**: #FFFFFF (Blanco)

## 📁 Archivos Incluidos
- `index.html` - Estructura principal del sitio
- `styles.css` - Estilos y diseño visual
- `script.js` - Funcionalidad interactiva
- `README.md` - Este archivo

## 🚀 Cómo Usar

### Opción 1: Abrir directamente en el navegador
1. Descarga la carpeta `public` completa
2. Haz doble clic en el archivo `index.html`
3. El sitio se abrirá automáticamente en tu navegador predeterminado

### Opción 2: Servidor local (recomendado)
Si necesitas probar con un servidor local:

**Con Python:**
```bash
cd public
python -m http.server 8000
```
Luego abre: http://localhost:8000

**Con Node.js:**
```bash
cd public
npx http-server
```

## 🎯 Personalización

### Cambiar Información de Contacto
Edita en `index.html`:
- Busca `(123) 456-7890` y reemplaza con tu teléfono
- Busca `info@aleluyagarden.com` y reemplaza con tu email
- Busca `Calle Principal #123` y reemplaza con tu dirección

### Cambiar Colores
Edita en `styles.css`:
- Busca `#FF8C00` para cambiar el naranja
- Busca `#5D3E7B` para cambiar el morado
- Busca `#4CAF50` para cambiar el verde

### Modificar Texto
Todo el contenido está en `index.html` y puede ser editado fácilmente.
