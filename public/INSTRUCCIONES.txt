📝 PERSONALIZACIÓN RÁPIDA:
═══════════════════════════════════════════════════════════════

Para cambiar TELÉFONOS:
→ Abrir index.html
→ Buscar: (123) 456-7890
→ Reemplazar con tu número

Para cambiar EMAILS:
→ Abrir index.html
→ Buscar: info@aleluyagarden.com
→ Reemplazar con tu email

Para cambiar DIRECCIÓN:
→ Abrir index.html
→ Buscar: Calle Principal #123
→ Reemplazar con tu dirección

Para cambiar COLORES:
→ Abrir styles.css
→ Buscar el código de color (ej: #FF8C00)
→ Reemplazar con tu color preferido
